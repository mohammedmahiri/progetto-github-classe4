# 🌿 FreshRoute — Landing Page

> Progetto scolastico · Classe 4ª Informatica · Gruppo 2

Landing page per **FreshRoute**, una startup di delivery km 0 che collega produttori agricoli locali con i consumatori della propria zona.

---

## 📁 Struttura del progetto

```
freshroute/
├── index.html   # Pagina principale
├── style.css    # Stile e layout
├── script.js    # Logica JavaScript (form, animazioni)
└── README.md    # Questo file
```

---

## 🎯 Requisiti implementati

| Requisito | Stato |
|---|---|
| Hero section con slogan e CTA "Iscriviti ora" | ✅ |
| Sezione "Come funziona" con 3 step visivi | ✅ |
| Sezione vantaggi con card descrittive | ✅ |
| Form iscrizione email con conferma dinamica (JS) | ✅ |
| Footer con link social e contatti | ✅ |
| Design responsivo mobile/desktop | ✅ |

---

## 🛠️ Tecnologie usate

- HTML5 semantico
- CSS3 (variabili, grid, flexbox, animazioni)
- JavaScript vanilla (validazione form, DOM manipulation)
- Google Fonts: Playfair Display + DM Sans

---

## 🚀 Come visualizzare il sito

1. Scarica o clona il repository
2. Apri `index.html` nel browser

Non sono necessari build tools o server: il sito funziona direttamente aprendo il file HTML.

## 📋 Scelte progettuali

- **Palette colori:** verde bosco (`#1e4620`) + arancio caldo (`#e07b2a`) + bianco crema — ispirata alla natura e alla sostenibilità come da brief.
- **Tipografia:** Playfair Display per i titoli (elegante, editoriale), DM Sans per il testo (leggibile, moderno).
- **Form JS:** validazione in tempo reale su ogni campo + messaggio di conferma personalizzato con nome, email e città inseriti dall'utente.
- **Responsività:** layout a griglia che collassa in colonna singola sotto i 900px.
